## Enunciado

Escolha uma base de código pequena que você já conheça (um projeto pessoal, ou um repositório de código aberto simples) e, com apoio de uma IA, implemente uma nova funcionalidade pequena mas real — por exemplo, adicionar um filtro de busca, um endpoint novo, ou uma validação de formulário.

## Como conduzir o exercício

1. **Antes de acionar a IA**: gaste 2 minutos entendendo a parte relevante da base de código e definindo um plano mínimo (Módulo 2, aula 1), narrando esse plano em voz alta.
2. **Primeiro prompt**: formule um prompt específico, mencionando contexto relevante do projeto (Módulo 1, aula 2).
3. **Revisão crítica**: antes de aceitar o resultado, aplique o checklist da aula de Revisão Crítica (Módulo 1) — casos extremos, consistência com o código existente, suposições implícitas.
4. **Iteração**: se necessário, refine com feedback específico (Módulo 2, aula 2), narrando por que cada ajuste foi pedido.
5. **Validação final**: revisite os requisitos originais da tarefa e confirme, item por item, que foram atendidos (Módulo 2, aula 3).

## Checklist de autoavaliação

- [ ] Você narrou o plano antes do primeiro prompt, em vez de acionar a IA imediatamente?
- [ ] Você revisou criticamente o resultado antes de aceitar, em vez de integrar de imediato?
- [ ] Você conseguiria explicar cada decisão central do código gerado, se questionado?
- [ ] Você testou o resultado contra pelo menos um caso extremo antes de considerar a tarefa concluída?
