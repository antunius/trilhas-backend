## Enunciados sugeridos

1. Dado um array ordenado, encontre se existem dois números cuja soma seja igual a um valor-alvo.
2. Dada uma string, encontre a maior substring sem caracteres repetidos.
3. Dado um array de números, encontre o subarray contíguo de tamanho k com a maior soma possível.

## Perguntas orientadoras

- O array ou string dado já está ordenado, ou a ordenação ajudaria a resolver o problema?
- O problema pede algo sobre um intervalo contínuo, ou sobre qualquer subconjunto (não necessariamente contíguo)?
- É possível atualizar a métrica de interesse de forma incremental, em vez de recalculá-la do zero a cada posição?

## O que revisar depois de resolver

- A solução ficou em tempo linear (O(n)), ou ainda existe algum loop aninhado desnecessário que poderia ser eliminado?
- Você identificou corretamente se o problema pedia ponteiros convergentes, ponteiros na mesma direção, ou uma janela deslizante?
