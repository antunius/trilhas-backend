## Enunciados sugeridos

1. Encontre os k elementos mais frequentes em um array de números.
2. Gere todas as combinações possíveis de parênteses balanceados para um número n de pares.
3. Encontre o menor valor de uma capacidade de transporte que permita mover todos os itens dentro de um número máximo de dias (bom candidato a busca binária sobre a resposta).

## Como praticar

Diferente dos exercícios anteriores, organizados por padrão, esta lista mistura propositalmente diferentes categorias — o objetivo aqui não é aplicar um padrão já sabido de antemão, mas praticar a etapa de reconhecimento (Módulo 3) do zero, como aconteceria em uma entrevista real com um problema desconhecido.

Para cada enunciado, antes de escrever qualquer código, pare e pergunte: "qual padrão do Módulo 2 esse problema mais se parece?" — e só depois de responder essa pergunta, comece a estruturar a solução.
