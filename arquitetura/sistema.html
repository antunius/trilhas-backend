Sistema, componente e fronteira

Analogia: o restaurante inteiro é o sistema. A cozinha é um componente. O cardápio é o contrato: o cliente não entra na geladeira.

Sistema é o todo que entrega uma capacidade (“cobrar e confirmar pedido”). Componente / serviço é um processo deployável com fronteira: API ou tópico que outros usam. Dentro você muda à vontade; do lado de fora, o contrato é lei. Contrato é o que o consumidor pode assumir: campos, semântica, erros, idempotência, versão. Quebrar contrato é incidente, mesmo com código “certo” no produtor.

Erro comum: tratar “serviço” como pasta no repositório. Sem fronteira de deploy e de dado, é módulo com DNS.
